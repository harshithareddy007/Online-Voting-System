# 🗳️ Secure E-Voting System

A full-stack **Secure Online Voting System** built using Django that enables safe, transparent, and efficient digital voting.

---

## 🌟 Features

### 👤 Voter Side
- Aadhaar + EPIC based authentication
- OTP verification (simulated)
- Secure vote casting
- One vote per voter restriction

### 🛠️ Admin Panel
- Upload voters via CSV
- Manage candidates
- Start / Stop elections
- View live results
- System logs and monitoring

### 🔐 Security Features
- Unique voter validation
- Duplicate prevention
- Session-based voting control
- Secure admin access

---

## 📊 Admin Dashboard Highlights

- Upload voter data with validation
- View complete voter list
- Manage candidates with party symbols
- Real-time election control
- Results visualization
